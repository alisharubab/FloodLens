# THEME.md — FloodLens UI/UX direction

This file is the design brain for FloodLens. Read it alongside CLAUDE.md. Every design decision follows from here, so judges never once feel they're looking at a default AI-scaffolded site.

**Prime directive**: nothing in this build should look like it came from a Vercel template. Craft over polish. Specific over generic.

> **Update — light theme.** The site ships as a light, warm-paper design. Everything below that
> describes a dark canvas is superseded by the palette in "Color palette": tokens are now
> `--canvas` / `--canvas-soft` (backgrounds), `--fg` / `--fg-dim` / `--fg-ghost` (text) and the
> accents `--flood` `--alert` `--warn` `--signal`, deepened for contrast on cream. Typography,
> layout, interaction and component rules are unchanged. Where this doc says `--ink` read
> `--canvas`, and where it says `--paper` read `--fg`.

---

## The "this doesn't look AI" test

If any of these are true, it looks AI-generated. Avoid every one:

- Font is Inter, Geist, Roboto, or system-ui
- Hero uses a centered headline + CTA button with no visual anchor
- Rounded cards in a 3-column grid with icon-title-two-lines each
- Default shadcn/radix components left unstyled
- Purple-to-indigo gradient background
- Glassmorphism cards with backdrop-blur
- Lucide icons everywhere at the same size
- "Fade in on scroll" as the only animation
- A hero image generated by an AI model
- A pricing table in a project that has nothing to sell

If you catch yourself writing any of these, stop and pick the specific craft version from the rest of this doc.

## Typography system (the single biggest non-AI lever)

### Fonts — all free via Google Fonts

**Display / editorial serif**: **Fraunces** (variable, with optical sizing)
- Use for the "FloodLens" wordmark and every big headline
- Weight 600-700, italic variant for tagline
- Why: variable serif with character, highly distinctive, not in any Vercel starter

**Body / UI sans**: **Space Grotesk** (variable, 300–700)
- Use for all body text, stat numbers, UI labels, nav
- Weight 400 for prose, 500 for UI, 700 for big numbers
- Why: strong personality, geometric but not sterile, nothing like Inter

**Mono (sparingly)**: **JetBrains Mono** (variable)
- Use for data captions, coordinates (e.g. "27.5°N, 68.5°E"), dates, metadata
- Adds scientific credibility without being nerdy-ugly

### Install via next/font

In `app/layout.tsx`:

```tsx
import { Fraunces, Space_Grotesk, JetBrains_Mono } from 'next/font/google'

const fraunces = Fraunces({
  subsets: ['latin'],
  variable: '--font-fraunces',
  display: 'swap',
  axes: ['opsz', 'SOFT', 'WONK'],
})

const grotesk = Space_Grotesk({
  subsets: ['latin'],
  variable: '--font-grotesk',
  display: 'swap',
})

const mono = JetBrains_Mono({
  subsets: ['latin'],
  variable: '--font-mono',
  display: 'swap',
})

// on <html> or <body>:
className={`${fraunces.variable} ${grotesk.variable} ${mono.variable}`}
```

Then in `globals.css`:

```css
:root {
  --font-display: var(--font-fraunces);
  --font-sans: var(--font-grotesk);
  --font-mono: var(--font-mono);
}
body { font-family: var(--font-sans); }
h1, h2, h3, .display { font-family: var(--font-display); font-feature-settings: 'ss01'; }
.mono { font-family: var(--font-mono); font-variant-numeric: tabular-nums; }
```

### Type scale (mobile-first, tight headlines)

- Hero headline: `clamp(3.5rem, 11vw, 8rem)` — big, dominates
- Section headline (H2): `clamp(2rem, 5vw, 3.5rem)`
- Sub-headline / lede: `clamp(1.125rem, 2vw, 1.5rem)`
- Body: `1.0625rem` (17px) with line-height 1.65
- Caption / meta: `0.8125rem` (13px), mono, uppercase, letter-spaced `0.15em`
- Massive stat number: `clamp(3rem, 8vw, 6.5rem)`, weight 700, grotesk, tabular-nums

Rule: display serif gets **-0.02em letter-spacing** on headlines. Captions get **+0.15em uppercase**. Nothing in between.

## Color palette

Named semantic colors. Not Tailwind indigo-500.

### Base canvas
```
--canvas: #fbf6ec       /* warm cream, primary bg (never pure white) */
--canvas-soft: #f0e8d6  /* secondary section bg */
--fg: #1a1030           /* near-black with purple undertone, main text */
--fg-dim: #4a4060       /* secondary text */
--fg-ghost: #6b6086     /* hints, metadata, deep muted */
```

### Accent (use SPARINGLY — these punch)
```
--flood: #00729a        /* deep cerulean — the "water seen by SAR" color */
--alert: #d10f47        /* hot magenta — stat emphasis, destructive */
--warn: #b07400         /* amber — callouts, highlights */
--signal: #2a9d2f       /* green — "signal detected", radar echoes */
```

### Rules
- Hero uses `--ink` with a radial soft glow of `--alert` top-right at 8% opacity (no gradient blobs)
- 90% of surface area is `--ink` or `--ink-soft`
- Accents appear ≤3 times per section
- Large stat numbers: `--alert` for the shocking ones (33M, 1739), `--flood` for context ones
- Body text: always `--paper`, never pure white
- Never hex a color inline in a component — use the CSS var

### Noise overlay (critical for non-AI feel)

Add a subtle noise/grain texture to the body:

```css
body::before {
  content: '';
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 100;
  opacity: 0.06;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 200 200' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noiseFilter'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.9' numOctaves='3'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noiseFilter)'/%3E%3C/svg%3E");
  mix-blend-mode: overlay;
}
```

This one detail does more than any color choice to kill the "AI site" feel.

## Layout system

### Grid
- 12-column grid, 24px gutter, max-width 1440px, 5vw side padding
- Sections full-bleed when content is imagery; constrained when text-only
- Asymmetric layouts: 7/5 or 8/4 column splits, not 6/6. Symmetry = boring.

### Section rhythm
Each section has one of 3 vertical paddings:
- `--space-tight`: 4rem top+bottom (minor transitions)
- `--space-normal`: 8rem (most sections)
- `--space-wide`: 12rem (hero, major breaks)

Never equal paddings between all sections — the rhythm should vary.

### Section anchors (editorial feel)

Every section has a small meta label in mono, uppercase, above the headline:

```html
<div class="mono uppercase text-xs tracking-widest text-paper-ghost">01 · The event</div>
<h2 class="display">A third of Pakistan went underwater.</h2>
```

This single pattern makes the page read as editorial, not SaaS.

## Interactivity (what judges remember)

Priority order — ship top to bottom, cut from the bottom:

### Must have (1-2 hours even in a sprint)
1. **Smooth scrolling** — install Lenis (`pnpm add lenis`), 5-line setup, instantly feels custom
2. **Scroll progress indicator** — thin cyan bar at the top that fills as you scroll (10 lines of CSS)
3. **Before/after swipe** — the hero interaction, obviously
4. **Hover state on the map pin** — pulse animation, cyan glow
5. **Stat numbers count-up on scroll** — framer-motion `useInView` + animated counter. ~30 min.

### Should have (if time allows)
6. **Scroll-triggered section reveals** — translateY + opacity, staggered children. Framer Motion `whileInView`.
7. **Cursor-follow on key sections** — a soft cyan radial that tracks the mouse (adds depth to hero)
8. **Marquee of SAR metadata** — thin ticker at bottom of hero scrolling: "SENTINEL-1 · C-BAND · VV POLARIZATION · DESCENDING PASS · 2022-08-28 · ORBIT 44567 · ..."
9. **Live "radar sweep" animation** — a conic-gradient rotating on the map pin, feels mission-control
10. **Scroll-linked image parallax** — SAR image zooms slightly as it enters view

### Nice to have (don't let these eat time)
11. Custom cursor on hover of the swipe handle
12. Easter egg: typing "SAR" anywhere triggers a radar ping sound
13. Dark mode / light mode toggle (SKIP — single dark theme is more confident anyway)

### Install

```bash
pnpm add framer-motion lenis
```

Smooth scroll setup (in a Client component wrapping `app/page.tsx` content):

```tsx
'use client'
import { useEffect } from 'react'
import Lenis from 'lenis'

export function SmoothScroll({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    const lenis = new Lenis({ duration: 1.2, smoothWheel: true })
    function raf(time: number) { lenis.raf(time); requestAnimationFrame(raf) }
    requestAnimationFrame(raf)
    return () => lenis.destroy()
  }, [])
  return <>{children}</>
}
```

## Component patterns

### Buttons
- Primary: pill-shaped, `--paper` background, `--ink` text, 1px solid `--paper`, hover shifts to `--flood` bg with `--ink` text
- Secondary: transparent, 1px `--paper-dim` border, `--paper` text, hover `--paper` border
- Mono caption underneath big CTAs: `→ public open-source · MIT`
- Never gradient buttons. Never drop shadows.

### Stat tiles
- Massive number in Grotesk 700, tabular-nums, color `--alert` or `--flood`
- Small uppercase mono label above: `PEOPLE DISPLACED`
- Thin 0.5px border-top in `--paper-ghost`, no border elsewhere
- 4 across on desktop, 2x2 on mobile
- NO cards. NO backgrounds. Flat on `--ink-soft`.

### Narrative / quote blocks
- Max-width: 55ch for prose
- First letter of a section drop-capped (Fraunces, 5 lines deep, color `--flood`)
- Pull quotes in Fraunces italic, 2rem, color `--paper`, with a 2px left border in `--alert`

### Images
- Every SAR image gets a thin 0.5px border in `--paper-ghost`
- Mono caption below in `--paper-dim`: `SENTINEL-1 · SINDH PROVINCE · 2022-08-28`
- No rounded corners on scientific imagery — ever. Square. Clinical.
- Rounded only on soft UI elements (buttons, inputs, pill chips)

### Map
- CartoDB Dark Matter tile layer (free, no API key, dark aesthetic)
- Pin: custom SVG — a pulsing cyan dot with 3 concentric rings
- Popup: no default Leaflet popup — custom, matches site typography

## Micro-details that kill it

- **Numbers are tabular-nums everywhere**: `font-variant-numeric: tabular-nums` so count-up animations don't jitter
- **No emoji anywhere in UI** — use mono arrows `→ ← ↗ ↓` or hand-drawn SVG icons if needed
- **Sentence case headlines, never Title Case**
- **Exactly one italic use per section** (overuse kills the effect)
- **Captions always include specific technical metadata** — judges read these and they signal depth
- **Load fonts with `display: swap`** so the fallback renders instantly, no FOIT
- **One custom favicon** — a tiny radar pulse SVG, not the Next.js default
- **Title tag**: "FloodLens — through clouds, through night" (not "Create Next App")
- **OG image**: a 1200x630 snapshot of the hero (make a quick one in Figma/Canva if time)

## Final gut check before submit

Open the deployed site, mute your brain, and look at it like a judge seeing it for the first time. Ask:

1. Does the hero land in one glance?
2. Is there any default Tailwind color anywhere? (If yes, swap for a semantic var.)
3. Does any section feel like a Vercel template? (If yes, break the symmetry or kill the section.)
4. Is there one piece of micro-interaction that makes a judge say "oh nice"? (If no, add the count-up or marquee.)
5. On mobile, does the hero still feel enormous? (If no, bump the clamp min.)

If all five are yes, you're shipping something impressive, not something generated.
